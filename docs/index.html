Vibewright

You vibe. It builds.

A free desktop app for Windows and macOS. Type one sentence – Vibewright interviews you, writes a needs analysis, plans the phases, checks your tools and then builds it step by step with Claude Code running inside the app.

Download for Windows & macOS View on GitHub

Idea → Interview → Needs analysis → Plan → Tool check → Build with Claude Code

What it does

Guided interview

One multiple-choice question per screen, your own answer always possible. Follow-ups only where something is missing.

Needs analysis

Goal, scope, must-have and non-goals, risks you didn't think of and a feasibility traffic light.

Plan as a roadmap

3–6 phases with clear "done when" criteria and concrete steps in plain language.

Tool check

Checks your PC and Claude setup (plugins, skills, MCP servers) and recommends only what a phase really needs.

Claude Code in the app

An embedded terminal runs Claude Code with a generated CLAUDE.md. Finished steps are ticked off live.

Obsidian or Markdown

Everything lands as Markdown in your Obsidian vault (Dataview, Kanban) or as .md files plus an HTML dashboard.

Git safety net

Optional: Claude commits after every finished step, so you can always go back.

Maintenance mode

Finished code projects pick up new GitHub or Gitea issues – nothing enters the plan without your click.

English & Deutsch

UI, Claude's texts and the generated files in both languages.
